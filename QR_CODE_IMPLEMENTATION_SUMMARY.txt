

🎯 QUICK START (Pilih salah satu)
═════════════════════════════════════════════════════════════════════════════

  OPTION 1: Auto Setup (Recommended) ⭐
  ┌─────────────────────────────────────────────────────────────────────┐
  │ > php artisan qr:setup-ip                                          │
  │                                                                      │
  │ ✓ Auto-detect IP                                                   │
  │ ✓ Update .env otomatis                                             │
  │ ✓ Done!                                                            │
  └─────────────────────────────────────────────────────────────────────┘

  OPTION 2: Manual Script
  ┌─────────────────────────────────────────────────────────────────────┐
  │ > php find-ip.php                                                  │
  │                                                                      │
  │ Copy IP address yang muncul, paste ke .env                         │
  └─────────────────────────────────────────────────────────────────────┘

  OPTION 3: Manual Edit
  ┌─────────────────────────────────────────────────────────────────────┐
  │ 1. ipconfig (di CMD/PowerShell)                                    │
  │ 2. Copy IPv4 Address (192.168.x.x)                                 │
  │ 3. Edit .env:                                                       │
  │    QR_LOCAL_IP=192.168.1.5                                         │
  │    QR_PORT=8000                                                    │
  │    QR_REWRITE_LOCALHOST=true                                       │
  │ 4. Save                                                             │
  └─────────────────────────────────────────────────────────────────────┘


🚀 THEN RUN
═════════════════════════════════════════════════════════════════════════════

  > php artisan serve
  
  Server akan running di: http://localhost:8000
  
  ✓ QR Code akan otomatis menggunakan IP: http://192.168.1.5:8000


📱 SCAN DARI HP
═════════════════════════════════════════════════════════════════════════════

  1. Pastikan HP di WiFi YANG SAMA dengan komputer
  2. Export PDF dari admin dashboard
  3. Buka camera/QR scanner di HP
  4. Arahkan ke QR code di PDF
  5. Klik link yang muncul
  6. ✓ DONE! HP bisa akses verifikasi dokumen

🚨 COMMON ISSUES & SOLUTIONS
═════════════════════════════════════════════════════════════════════════════

  ❌ "ERR_REFUSED_STREAM"
  → Firewall blocking port 8000
  → Solution: Allow port 8000 di Windows Firewall

  ❌ "Network Unreachable"
  → HP tidak di WiFi yang sama
  → Solution: Hubungkan HP ke WiFi yang sama

  ❌ "QR masih localhost"
  → Cache not cleared
  → Solution: Ctrl+Shift+Del clear cache atau restart server

  ❌ "IP tidak terdeteksi"
  → Auto-detect gagal
  → Solution: Manual set di .env: QR_LOCAL_IP=192.168.1.5
